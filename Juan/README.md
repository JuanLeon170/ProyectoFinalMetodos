**Estudiante:** Juan Carlos León Ramos

## Resumen del Trabajo
Se implementaron desde cero los métodos numéricos para resolver la EDO de secado de café:
$$\frac{dM}{dt} = -k(M - M_e)$$

### Archivos asignados:
* `src/metodos_edo.py`: Implementación de Runge-Kutta 4º Orden (RK4), Euler y cálculo de parada.
* `tests/test_rk4.py`: Pruebas comparativas de precisión entre métodos.
